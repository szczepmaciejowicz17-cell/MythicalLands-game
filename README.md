# Mythical Lands

Game package for players. Download the newest version here:

**https://github.com/szczepmaciejowicz17-cell/MythicalLands-game/releases/latest**

Unzip `MythicalLands.zip`, run `MythicalLands.exe` (if Windows says "Windows protected your PC", click
"More info", then "Run anyway"), create an account and a character. The server address is already
filled in.

When the game says your files do not match the server, download the newest version from the same link.
